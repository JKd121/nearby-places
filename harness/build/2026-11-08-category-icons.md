# 类别图标与顶部独立控件整合（2026-11-08）

用户确认图标草图后，要求在真实工作台中实现，服务类别上移，取消大外框，保留静息硬阴影与悬停加重。

## 实施

- 五组独立按钮直接排列于标题下方，半径与搜索按钮同排；窄屏自然换行。条件区没有边框、背景卡或阴影，阴影由每个独立控件管理。
- 共享 `category-shapes.ts` 图形定义，分别供 React `CategoryIcon` 与原生地图 SVG DOM 使用。父类分别为床、购物袋、餐具、游戏手柄、公共交通；十个子类均有独立图形。
- 条件选择、子类菜单、分类结果标题、原生地图单点及选中标记共用图标；预览页也改为复用这些组件。
- 静息阴影为 `4px 4px 0 #111`，悬停／键盘聚焦为 `6px 6px` 并向左上位移 2px，按下为 `2px 2px`。减少动态效果偏好保留阴影变化，关闭位移动画。
- 真实搜索工作台采用紧凑侧栏／内容布局，去除重复顶部导航与面包屑空间；保留身份提示、个人中心、历史、导航折叠、排序及翻页功能。

## 验证

- 核心／Route 317 项、AST 22 项、规则兼容 6 项、运行时 3 项测试通过；类型检查、Lint 通过。
- 四组浏览器业务回归通过：流式结果／中断、桌面图标／阴影／布局／排序／第二页、手机重试／同坐标聚合／身份清理、20 轮取消与资源释放；最终桌面／手机检查再次通过。
- 真实高德 UI 检查使用已经验证的深圳北站坐标，仅执行 1 次酒店搜索，返回 25 个地点；共享 SVG 选中标记、列表定位、静息／悬停阴影、390px 切换及无横向溢出通过。
- 实测截图与布局／阴影记录位于 [证据目录](category-icons-2026-11-08/)。独立浏览器使用匿名身份，未修改账户凭证。

生产构建通过；生产构建下 6 组 Chromium 测试全部通过，其中桌面／390px 各在 4 倍 CPU 降速下执行 20 次 500 点更新，可见反馈 p95 分别为约 123.1ms／84.4ms，均满足 ≤150ms 目标。具体值保存在 `map-search-2026-11-08/performance-desktop.json`、`performance-mobile.json`，这些数据为 SDK 合约夹具测量。最后的图标线色修订已完成最终构建复核，本机入口再次返回 HTTP 200。
