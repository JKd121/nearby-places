## 桌面组成（推荐方案）

```text
┌──────────────┬───────────────────────────────────────────────┐
│ 地点周边     │ 探索附近             [地点输入] [解析地点]    │
│              │ 输入地点，确认中心，再发现附近服务。            │
│ ● 探索附近   ├───────────────────────────────────────────────┤
│ ○ 最近搜索   │ [搜索中心] [搜索半径] [已选类别] [本次已获取]  │
│ ○ 个人中心   ├───────────────────────────┬───────────────────┤
│              │ 主区域 · 约2/3            │ 侧区域 · 约1/3    │
│              │ 候选 / 引导 / 搜索结果    │ 当前中心          │
│              │                           │ 5组类别选择       │
│              │ 类别过滤 + 排序           │ 1/2/3/5km         │
│              │ 地点列表 + 加载更多       │ [搜索附近]        │
│              │                           │                   │
│ 高德地点数据 │                           │                   │
└──────────────┴───────────────────────────┴───────────────────┘
```

- 应用外壳：借鉴用户两张图的层级，新增紧凑全宽品牌顶栏，右侧为带图标的“折叠导航/展开导航”；其下为左侧导航和自适应内容区。内容区顶部有“工作空间 / 探索附近”或“个人空间 / 个人中心”位置提示，右侧小人图标可进入同一静态个人中心。保持米白网格、黑描边、硬阴影和当前配色，不采用参考图的灰白线框视觉。
- 左栏：默认展开约240px，折叠约72px；“工作空间”组包含探索附近（搜索/定位图标）、最近搜索（时钟图标），“个人空间”组包含个人中心（人像图标）。选中项仍为粉底黑边。展开显示图标和文字，折叠仅显示同一组图标，隐藏组标题并保留完整可访问名称及hover/focus提示。底部数据来源在折叠时可简化但保留可访问说明。
- 折叠只调整布局宽度与本地UI状态，内容区通过flex/grid重新分配空间；不能遮盖、缩放裁切原内容或重置查询。折叠/展开按钮为原生button，提供aria-expanded与aria-controls，切换后焦点留在按钮。约160ms宽度过渡，减少动态偏好下即时变化；不写localStorage、cookie、用户偏好或后端。
- 导航使用内部视图切换，入口保持 `/`；不借本次改版扩展路由。SearchApp/store 保持挂载；去看历史不清空输入、中心、结果或中止已有状态。返回探索保持原状态。
- 顶部：主标题36px、说明16–18px；同一区域只有一个地点输入框及“解析地点”。修改输入继续遵守原中心失效规则。移除旧版高占屏宣传区。
- 四卡：搜索中心（短名＋状态）、搜索半径（默认3km）、已选类别（默认10/10）、本次已获取（搜索前为“—”，成功后为实际去重结果数）。不是城市全量POI数；失败/等待不能伪装成0。数字约30px，图标容器40px。
- 主次区域：可用宽度足够时约2:1，右栏最小约300px；桌面工作台以100dvh分配高度，顶栏和摘要占自然高度，其余空间给主面板和右栏。主面板内部标题/过滤/排序保持可见，只有列表区域纵向滚动，长列表不增高外框。使用flex/grid的min-height:0与overflow-y:auto等标准布局；原生滚动条可拖，预留滚动条槽位防止内容跳动。右侧条件超出自身可用高度时独立自然滚动，确保底部主按钮可到达。
- 初始状态：主区简洁说明“先输入并确认一个地点”；右区提示确认中心后可设置范围。摘要显示实际默认条件；未确认前不提供可提交的附近搜索表单。
- 位置确认后：候选列表卸下，原框立即切换为“附近结果”，内容先显示“已确认中心，设置条件后搜索”；右区展开条件。按现有语义点击“搜索附近”才查询。10类按住宿/购物/餐饮/娱乐/交通分组，保留全选、清空及整组操作。
- 结果：主区顶部保持过滤和排序，列表单列。每行优先级为名称/距离 → 类别/可用评分与消费 → 营业时间 → 地址/高德查看位置。名称和地址允许换行，关键操作保持可见。
- 最近搜索视图：隐藏探索摘要和条件栏，显示通栏记录卡；标题“最近搜索”，说明“点击地点，沿用原条件重新搜索”。每条含确认名称、地址、类别数和半径；保留逐条删除和读取失败重试。无记录显示空态。使用已有最多10条，不声称完整历史。输入框历史入口与左栏入口打开同一视图，不重复渲染两个历史列表。
- 历史回放：点击记录 → 恢复现有中心/条件 → 回到探索并宣布“正在搜索…” → 显示新结果；不再确认候选，也不触发额外解析。
- 个人中心：点击导航或顶栏人像图标，进入同一外壳内的独立静态视图，原搜索组件/store保持挂载。内容为：标题“个人中心”及“功能建设中，以下为布局预览”；左侧访客概览卡（通用人像图形、“访客”“未关联账号”，不读取真实身份）；右侧个人资料卡（昵称/邮箱/所在城市/简介等只读占位）；下方偏好区域预留卡（静态样式行，明确“尚未开放”）。字段仅显示未设置/未关联，不展示虚构用户或收藏数。
- 个人中心功能边界：仅前端组件、样式、当前视图与侧栏开合状态；不调用账号、登录、注册、保存、上传、资料编辑、偏好持久化、收藏、统计等业务函数；不增加API、schema、数据库写入、外部跳转或存储。不放可提交的表单、“保存”或“登录”按钮。未来能力的展示控件均为不可操作占位并配说明。个人中心自身不发请求；原页面已发起的合法搜索或历史刷新不因切换视图被误认为个人中心新增调用。
- 候选仍先显示5项，面板内“查看更多地点”展开其余已返回候选，新增条目仍进入同一滚动区。结果滚动只浏览已加载数据；现有本地“加载更多”和特定类别provider page2按钮位于滚动列表末尾，不改成无限请求或新增自动分页。
- 切换候选→附近结果、修改查询中心、结果分类切换时，主列表滚动位置回到顶部；加载更多时保留现有位置。选定候选后将焦点落到新面板标题或条件入口，避免焦点留在被移除节点。切去历史/个人中心再返回探索保持已有查询状态和合理的滚动位置。

## 状态与交互

| 状态 | 用户看到的内容和可执行操作 |
| --- | --- |
| 初始 | 可输入、清空地点、查看最近搜索；摘要中的未搜索值为“—” |
| 解析中 | 按钮显示“解析中…”并禁用重复提交；候选区域显示占位与文字状态 |
| 多候选 | 主区内联有界滚动列表，前5项＋框内查看更多；每项显示名称、区县、地址和“选用此地点”含义；不弹窗遮挡输入 |
| 已确认 | 原面板已切换“附近结果”及待搜索提示，候选不再存在；右区显示中心/类别/半径、主按钮“搜索附近” |
| 无类别 | 显示“至少选择一个类别”；搜索按钮禁用，不能只用颜色表达 |
| 搜索中 | 主区显示列表骨架和“正在搜索所选的N个类别”；保留已确认中心；不显示虚构百分比或逐类完成进度 |
| 结果 | 真实条目、过滤、合法排序、现有两级加载更多；摘要总数不随本地过滤变成全量计数 |
| 部分类失败 | 顶部简短警示、失败分类标签；成功结果继续可看；不增加没有接口支持的逐类重试 |
| 全局/全部类别失败 | 展示错误及重试原操作入口，保留可用的中心和条件；不写“附近没有地点” |
| 无结果 | 说明当前范围/类别没有结果；可改半径或类别再主动搜索，不自动扩大查询 |
| 分页失败 | 保留已加载列表，显示原错误和可再次点击的获取更多按钮 |
| 历史读失败 | 保留已有可见记录，内联错误及现有重试；不挤掉结果 |
| 历史删失败 | 复用现有store恢复/错误机制；焦点移到合理的下一条或历史入口 |
| 历史保存失败 | 继续沿用现有 best-effort 行为，不阻断搜索结果，不新增本轮未覆盖的数据恢复机制 |

状态色用作胶囊且始终配文字：绿＝已确认/成功，黄＝等待/注意，紫＝当前选择，珊瑚红＝失败。粉色专用于主操作和选中导航。普通可读行无需响应纯装饰性悬停位移；可交互卡片才使用规定反馈。

## 视觉规格与中文适配

- 底色 `#fdf9f0`；24px正交网格，墨色 `#111111` 的5%不透明度；白色内容卡；不用旧版玻璃模糊和渐变。
- 配色完整沿用：粉 `#ff3d81`、绿 `#3ddc97`、黄 `#ffd23f`、紫 `#c8a2ff`、珊瑚红 `#ff6b5e`。使用黑字，避免小号白字落在亮粉上。
- 所有卡片/按钮2px墨色边框；卡片18px圆角、按钮8px、标签/导航胶囊。主要卡6px硬阴影，按钮/标签4px，强调区域最多9px，全部0模糊。
- 可交互卡hover左上2px；按钮hover左上1px、阴影5px；active右下2px、阴影0；按钮100ms。仅对transform/box-shadow/background等必要属性过渡，不用all；减少动态偏好下取消位移。
- 字体：拉丁标题Archivo Black，拉丁正文Space Grotesk，数值Space Mono；中文优先本机 `PingFang SC` / `Microsoft YaHei` 等无衬线字族，标题700–900，正文400–600。英文三字族建议仅使用所需字重和拉丁子集，通过构建期自托管并保留系统回退；具体资源许可与可获取性在实施时核对。不得为追求中文造型自动加载整包中文字体。
- 文字层级：桌面主标题36px、面板标题20px、正文/表单14–16px、次要信息12–14px；正文行高约1.5，中文标题不套英文uppercase或负字距。
- 间距以8px为基础：桌面主区内边距24–32px、卡片间距20–24px、内部16–20px；手机16px；硬阴影边缘要留出可见空间。
- 图标采用少量一致的定位、搜索、时钟、箭头线性图形；不用新增图像素材或伪造店铺照片。交互目标建议不小于44px。

## 响应式与键盘

| 可视宽度 | 布局 |
| --- | --- |

- 手机上过滤标签可横向滚动，排序另起一行；结果行、候选、历史改为上下结构，长地址换行，删除和查看位置目标保持可点。
- 375px、390px、820px、1440px均检查；200%缩放不遮挡操作；不以body overflow-x:hidden掩盖溢出。
- 低高度窗口或200%缩放时允许外层必要的布局滚动，以到达输入和表单，但候选/结果列表仍保持有界滚动；不得用整页overflow:hidden裁掉控件。键盘进入滚动区后方向键/PageUp/PageDown可浏览，Tab可离开，不产生滚动或焦点陷阱。
- 原生checkbox/radio/select，明确label、fieldset/legend；可见焦点；选中状态有文字/形状；状态文字使用合适的aria-live。
- 个人中心在窄屏改为概览→资料→预留区域的单列，静态说明不被遮挡。桌面/平板核验导航展开与折叠两态、hover/focus提示、内容重排和搜索状态保留。
- 最近搜索切换、回放与删除后有合理焦点落点；结果分类沿用语义时补齐对应键盘行为（如方向键/Home/End及Tab焦点策略），不能只有外观上的tab。
- 摘要是输出，不伪装按钮；条件收起按钮提供aria-expanded/aria-controls；清空输入后焦点回输入框。

## 实施边界与协作

- 主要影响：`app/page.tsx`、`app/globals.css`、`app/layout.tsx`（字体与整体包装）、`src/web/SearchApp.tsx`（展示结构）；只按必要性新增少量外壳/展示组件和浏览器测试。
- 复用不改：历史store、useSearchHistory、逻辑格式化/排序函数、API和数据结构。若候选确认、查询时机、历史回放或分页语义需变更，先修订方案。
- SearchApp保留现有处理函数、requestId保护和请求参数，尽量只调整渲染区。性能分支合并时逐项核对已有诊断调用，不整段覆盖事件函数。
- 本地单目录不能隔离其他聊天对该目录的写入：实施前检查状态，发现外来变动即核对归属；不得stash/提交/覆盖他人新改动。已有`b368`继续独立工作。
- 旧UI分支不自动合并；本次是当前master基础上的独立视觉提案，不表示旧UI阶段已获验收或可清理。
- 不恢复历史分支stash，不修改环境变量，不迁移数据库，不推送/合并/部署。功能联调使用明确选择的隔离预览数据，不默认写生产库。
