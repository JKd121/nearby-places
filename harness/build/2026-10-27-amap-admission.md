# 最小 Stage B / B-Q 本地交付（2026-10-27）

## 授权与范围

用户明确要求实现已对齐的 PostgreSQL 限额与速率闭环，验证后转渐进式类别搜索。沿用 `高德请求安全基线` / `b849deb`，不切换分支、不处理性能 Worktree、不提交推送部署，保留进入任务前的文档差异及两份审查包。

## 实现

- `AmapResource` 主协调表保存日/月策略、上海周期用量、预约尾部、时间消费水位及最终速率状态；`AmapOperationBinding` 只保存逻辑凭据／操作／资源映射，不保存 Key。第一版只选择环境配置的当前 Key。
- 统一服务端工厂必需注入准入，AST 门禁检查遗漏；Web 三个 Route 均受保护。CLI 调研脚本保持独立，不能在保护启用后未经核算共享使用同一 Key。
- 预约不扣预算；等待不持有连接；最终事务共同提交预算与许可。预约时间身份严格递增，消费水位拒绝重复或更旧预约；政策触发器递增版本并保留速率屏障。
- 上海日/月懒更新，无定时任务。额度不足 429 + 稳定错误码／retryAt，不自动禁用；下一周期由新请求恢复判断。数据库故障和提交不确定 503；所有准入失败都是请求级终止。
- 预约、有效许可和业务请求均有期限；许可在实际 fetch 前单次检查，不自动 HTTP 重试、不返还。独立有界准入池和本地入口保护不改变历史池。
- 实测发现预约与最终事务几毫秒抖动会误拒绝。处理为一次额外的可取消就绪等待／复查（非 SQL 失败重试，非轮询）。正常最多预约一次、最终检查两次；所有路径仍共用原始期限。

## 启用边界与下一步

迁移不种入生产政策，资源默认禁用，缺少映射会安全返回 503。上线前须明确目标数据库，核实每个操作真实共享范围，配置实际日/月预算与资源绑定；500ms、2s、300ms 宽限、200ms 许可时限和连接超时均需部署环境验证。策略共享范围不同的资源不能硬合并；不支持在线删除重建 scope 或清空状态。

不声称高德接收端严格 2 QPS；实例调度、网络延迟、数据库故障切换／时钟跳变和 Vercel 真实断连仍有环境边界。预扣后取消／许可过期可能保守损耗预算。取消请求不等同于物理 SQL 已停止，服务器超时独立兜底。

本地闭环已验证，后续进入渐进式类别搜索的具体交互和请求拆分；本次未开发 UI。生产启用、真实额度配置、提交／PR／部署按后续明确授权执行。
